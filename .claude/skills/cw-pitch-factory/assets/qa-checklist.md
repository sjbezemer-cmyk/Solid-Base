# QA-gate — lever pas op als alles ✅

## Inhoud / narratief
- [ ] Executive summary = **SCQA** en staat op zichzelf (antwoord eerst).
- [ ] Elke titel is een **action title** (conclusie, niet onderwerp).
- [ ] Twee **deep-dives**: huurder fully aware & aligned + de werken organiseren.
- [ ] **Klant-eigen woorden** uit de samenvattingsmail letterlijk verwerkt.
- [ ] Golden thread `KLANT DECIDES · C&W DELIVERS · HUURDER ALIGNED` op elke content-slide
      (behalve cover, teampagina, slotslide).
- [ ] Beleggerstaal (asset value, tenant retention, de-risking).

## Structuur
- [ ] 24 slides, juiste volgorde.
- [ ] **Slide 21 (Team) leeg/wit.**
- [ ] Placeholders zichtbaar (`€ [ • ]`, `[ FOTO ]`, `[ dashboard mock-up ]`).

## Huisstijl (tokens)
- [ ] Kleuren exact = gemeten tokens (navy #1F1942 / amber #F4B634 / cream / wit) — geen benadering.
- [ ] Fonts bevestigd (Arial + serif) of gesampled uit het referentiedeck.
- [ ] Sectielabel amber HOOFDLETTERS + navy descriptor; geen rood/charcoal.

## Proof
- [ ] Proof **gerenderd en visueel bekeken** (nooit blind).
- [ ] Geen tekst buiten kaders (shrink-to-fit aan); geen botsingen (bv. logo/subtitel).
- [ ] Geen interne notities gelekt ("in design uitwerken" e.d.).

## Handoff
- [ ] Attach-lijst compleet: slides.json/spec · referentiedeck-PDF · proof.pptx · CLAUDE-DESIGN-BRIEF.md.
- [ ] Openstaand duidelijk gemarkeerd: fee-bedragen, referenties, team, planning-jaartallen, foto's, techniek-verificatie.
